# Benchmark Fixtures

AstroWiki benchmarks use small, fixed corpora to validate migration and content quality.

V1 expects two fixture families:

- `s2fitting-noria`: small N132D/RGS sample derived from a NORIA-style wiki.
- `final-project-scaling`: small galaxy-cluster scaling sample derived from a course-project wiki.

Fixtures should contain only compact Markdown extracts and metadata needed for validation.
